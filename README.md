# My Food Stall POS

A private, cross-platform (Android & iOS) restaurant/food-stall POS application optimized for fast counter ordering, offline-first reliability, and real-time synchronization.

## Features
- **Fast Counter Ordering**: POS layout optimized for touch and speed.
- **Cross-platform**: Runs seamlessly on Android and iOS devices.
- **Offline-First**: Keep taking orders when the internet drops; syncs automatically when reconnected.
- **Realtime Sync**: Orders, status updates, and payments sync instantly across all devices.
- **Full POS Workflow**: KOT/Kitchen system, bill generation, multi-payment tracking (Cash, UPI, Card), daily sales reporting.
